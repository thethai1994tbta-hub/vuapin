DEPLOYMENT OPTIONS
================================================================================

1. LOCAL DEVELOPMENT (Built-in Flask server)
   - Use: python server.py
   - Port: 5000
   - Notes: Debug mode enabled, suitable for development only

2. GUNICORN (Recommended for Linux/Mac)
   - Command: gunicorn -w 4 -b 0.0.0.0:5000 wsgi:app
   - Workers: 4 (adjust based on CPU cores)
   - Benefits: Stable, widely used, easy to scale

3. DOCKER (Container-based deployment)
   - Build: docker build -t vuapin-app .
   - Run: docker run -p 5000:5000 --env-file .env vuapin-app
   - Benefits: Portable, consistent environment

4. HEROKU (Cloud PaaS)
   - Requires: Procfile (already configured)
   - Deploy: git push heroku main
   - Benefits: Automatic scaling, easy deployment

5. NGINX (Reverse proxy + production server)
   - Frontend: Nginx reverse proxy
   - Backend: Gunicorn app server
   - Benefits: High performance, load balancing

================================================================================
KNOWN LIMITATIONS & NOTES
================================================================================

1. Email Confirmation
   - Requires valid Gmail credentials
   - Uses Gmail SMTP (smtp.gmail.com:587)
   - Gmail app passwords required (not main password)
   - May need to enable "Less secure apps" or use 2FA app password

2. Product Images
   - Currently stored as URLs in database
   - Ensure URLs are accessible and CORS-friendly
   - Consider CDN for production image delivery

3. Database
   - SQLite used (suitable for <1000 orders/day)
   - For high traffic, migrate to PostgreSQL or MySQL
   - Regular backups recommended

4. Shopping Cart
   - Stored in localStorage (client-side)
   - Limited to 5-10MB depending on browser
   - Not synced across devices

5. QR Code
   - Requires internet connection for library loading
   - Fallback to manual bank transfer info provided
